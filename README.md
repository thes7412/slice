# 斬不盡的紙

用宿儺與五條悟的招式攻擊一張白紙。每一道傷口各自癒合，並像魔虛羅一樣適應：法陣每轉一格（共 8 格），該類攻擊造成的傷口瞬間全癒，之後癒合更快、傷口更小。

**宿儺**：解、捌、蜘蛛之絲、竈・開、伏魔御廚子；在解或捌按住不動詠唱「龍鱗 反発 番いの流星」，唸完放開即為世界を断つ斬撃（捌版本是網格狀）
**五條悟**：蒼、赫、茈、無量空處

法陣共六個：斬擊（解、捌、蜘蛛之絲、領域）、火焰、蒼、赫、茈、無量空處，各自分開適應。無量空處被適應後，領域中的傷口只會癒合變慢而不是完全停止。世界を断つ斬撃無法被適應；無量空處期間法陣停轉、傷口不癒合。

紙中央懸浮著魔虛羅的大法陣：任何一種適應升一格時轉一格，紙面掠過一層像油膜反光的流動彩虹光澤，被攻擊會晃動但不會壞。法陣正下方的紙不見時，要等有招式升一格、法陣轉動的那一刻才發動再生：碎片飛回原位拼好，同時紙從法陣中心往外長回整張；觸發轉動的那招適應越少，再生越慢（1 格約 2.6 秒，滿 8 格約 0.7 秒）。沒有轉動時，破洞照各招式原本的方式恢復。

魔虛羅只能用「還沒完全適應」的招式一擊消滅：單一招式在紙原本完好的情況下把整張紙打到一點不剩，法陣就會碎裂掉落化成黑泥。之後按「重新召喚」，唸完「布瑠部由良由良」後法陣與紙重新出現，所有適應歸零。實際上只有沒被適應的開、或未適應的無制限茈做得到（被適應後會留下殘骸或碎片）。

- 開：按住往後拉弓瞄準，放開射出火箭，火勢從落點往外燒出一大片不規則範圍；未適應時燒到的紙完全消失、再在原位長回，被適應後燒的範圍變小，燒過的地方留下越來越大、越來越淺的焦黑殘骸再恢復
- 竈：伏魔御廚子展開中施放，從圈心往外燒掉領域內的粉塵，領域隨之結束；被適應後燃燒範圍從圈心縮小，並和開一樣留下焦黑殘骸
- 蒼：按住拖曳，光球撕下紙片捲在周圍並把附近的紙吸過去，放開壓爆；按住不動詠唱「位相 黄昏 智慧の瞳」發動出力最大；撕開的每道裂痕各自計時，按住不放時也會陸續合回
- 赫：點一下，紅色光球凝聚約 0.25 秒後爆出衝擊波；按住不動詠唱「位相 波羅蜜 光の柱」，唸完放開原地超大爆炸
- 茈：按住不動詠唱「九綱 偏光 烏と声明 表裏の間」，唸完放開釋放 200%；被適應後光束帶裡會殘留細小碎屑
- 伏魔御廚子：點一下全畫面；用手指畫一圈決定範圍（自動變成等面積的圓），圈越小斬得越密，持續約 5 秒
- 虛式「茈」・無制限：出力最大的蒼還在場上時，切到赫點在蒼上，兩球融合，1 秒後放出無制限茈；倒數中切到茈按住可完全詠唱，唸完覆蓋整個畫面；被適應後爆炸範圍內會殘留碎片，越靠外圍越多
