# 斬不盡的紙

用宿儺與五條悟的招式攻擊一張白紙。每一道傷口各自癒合，並像魔虛羅一樣適應：法陣每轉一格（共 8 格），該類攻擊造成的傷口瞬間全癒，之後癒合更快、傷口更小。

**宿儺**：解、捌、蜘蛛之絲、竈・開、伏魔御廚子（結束時點火）；在解或捌按住不動詠唱「龍鱗 反発 番いの流星」，唸完放開即為世界を断つ斬撃
**五條悟**：蒼、赫、茈、無量空處

法陣依攻擊性質分三種：斬擊、火焰、無下限。世界を断つ斬撃無法被適應；無量空處期間法陣停轉、傷口不癒合。

- 竈・開：點一下大爆炸，燒光整個畫面後從外圍長回來
- 蒼：按住拖曳，黑洞經過處被吸出破洞
- 茈：按住不動詠唱「九綱 偏光 烏と声明 表裏の間」，唸完放開釋放 200%
- 伏魔御廚子：按住拖曳決定範圍，範圍越小斬得越密，結束時點火
